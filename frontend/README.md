# frontend

**Frontend не входит в 0.0.1** (§55, §74).

Каталог существует как зарезервированное место, чтобы структура репозитория отражала целевую архитектуру и не пересобиралась при появлении UI.

Предварительный стек (§55):

```text
TypeScript
React
Vite
```

Он выбран под сложные задачи интерфейса: виртуализированный timeline, графики, отображение графа процессов.

Решение о desktop-обёртке (локальный web UI, WebView2 host или другой shell) **сознательно не принимается** до появления работающего интерфейса (§55).

Что важно помнить при проектировании UI:

- UI не читает SQLite напрямую — только через API Core (§81, инвариант 10);
- порядок работы проекта: сначала data pipeline, потом интерфейс. Главные риски Chronoscope — корректность event model, стабильность сбора, объём данных, идентичность процессов, ordering, storage, privacy и производительность запросов, а не внешний вид (§56).
