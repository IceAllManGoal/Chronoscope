# analytics

Пакет для будущей аналитики. **В 0.0.1 он пуст** — здесь нет кода, и это осознанное решение, а не незавершённая работа.

Что появится позже (§45):

- статистические baseline без обязательного ML: median, percentiles, rolling average, standard deviation, EWMA;
- частота, first seen / last seen, распределения по времени суток;
- обнаружение редких связей («такое отношение родитель–потомок не наблюдалось последние 30 дней»);
- объяснимые отклонения вида «chrome.exe использовал 3.2x от медианного RAM за 30 дней».

Что сюда **не** попадёт:

- correlation engine — отдельная подсистема со своей моделью relationships (§22, §23);
- enrichment — хранится отдельно от событий и имеет собственную версию, timestamp и источник (§21).

Инварианты, обязательные для всего, что здесь появится:

1. Analytics строится **поверх** событий, а не вместо них (§81, инвариант 9).
2. События исторически неизменяемы: результаты анализа хранятся отдельно и не переписывают `Event` (§21).
3. Результаты анализа должны быть **воспроизводимыми и объяснимыми**: пользователь вправе увидеть, из каких событий получен вывод (§92).
4. Не оптимизировать без измерений (§61).
